SustainAI — Smarter Sustainable Choices, Powered by AI

Live Demo GitHub Profile

SustainAI is what I built for my Green Skills & Applied AI internship — a Flask app that tries to make sustainability decisions a little less abstract. GreenRoute AI is the core of it: pick a route, and it works out the CO2 cost, a Green Score, and what you'd save by choosing differently. The AI Coach and food donation guidance were added once that core was solid.

Python Flask Jinja2 HTML CSS JavaScript Chart.js Google Gemini API
01

GreenRoute AI

  • Calculates travel-related CO2 emissions based on trip details
  • Calculates a green score for selected travel routes
  • Shows potential CO2 savings across alternative options
  • Provides personalized sustainability suggestions
02

Food Donation Assistant

  • Helps users evaluate surplus food for donation eligibility
  • Provides general donation and safe storage guidance
  • Includes appropriate food-safety disclaimers and tips
03

AI Sustainability Coach

  • Integrated with Google Gemini API for natural language assistance
  • Generates sustainability-focused explanations and tips
  • Context-aware guidance based on user queries

Dashboard & Visuals
